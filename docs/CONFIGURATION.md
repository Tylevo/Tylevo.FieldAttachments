# Configuration

Press **F12** and open the Field Attachments settings.

| Setting | What it does |
| --- | --- |
| Enabled | Turns the attachment menu on or off. |
| Allow attachment changes | On for fresh installs. Allows installing, removing and replacing parts. Turn it off to browse without moving items. |
| Attachment menu key | Left Alt by default. Choose an unused keyboard key or mouse button, with optional modifiers. Clear disables the shortcut. |
| Menu activation (Hold / Toggle) | Hold is the default: keep the shortcut held to use the menu. Toggle opens it with one press and closes it with the next. |
| Cycle mounting position | Alt+R selects another mounting point for the open list or hovered card. |
| Switch attachment layer | Middle mouse switches between Basic and Multitool parts while the menu is open. Switching layers does not change attachments. |
| Cursor speed | Adjusts how quickly the menu cursor moves. |
| Attachment animation speed | Adjusts install and removal speed. Ordinary firing, reloading and inspection keep their usual speed. |
| Show attachment thumbnails | Shows item pictures in the menu. |
| Follow weapon movement | Makes the cards follow the weapon. |
| Idle movement | Gentle breathing movement in attachment view. Defaults to 0.5; 0 turns it off. Settles while browsing and pauses during a click. |

In Toggle mode with Alt as your menu key, using Alt+R or clicking while holding Alt keeps the menu open. Tap Alt on its own to close. Other keys and mouse shortcuts close on the next press.

The bottom hints show your saved shortcuts. On a fresh install, hold Left Alt to open the menu, press middle mouse to switch layers, and use the wheel to browse an open list. Scrolling never installs a part; click a part to fit it. Updates preserve your saved bindings.

Changing the menu key does not change the mounting-point or layer shortcut. Middle mouse is assigned to layers by default, so choose a different menu shortcut unless you also change the layer binding. If both use the same button, the menu shortcut takes priority while its modifiers are held. For combinations, hold the modifier first, then press the main key or mouse button.

When setting a combination in F12, release the main key or mouse button before releasing the modifier. For Ctrl + Middle Mouse, keep Ctrl held until you have released middle mouse.

Left/right click, Escape, Tab and F12 stay reserved for menu controls. Choose a binding that does not conflict with your other game controls.

Updates keep your saved settings. See the [user guide](USER_GUIDE.md) for controls and [troubleshooting](TROUBLESHOOTING.md) for help.
