# Animation and layout pipeline

Attachment mode has a separate authored presentation. The local complete source package routes 194 registered templates through 129 pinned bundles and 26 verified aliases. Exact weapon and rig identities select a supported presentation; unknown or mismatched cases are refused without starting native inspection.

The runtime samples a private skeleton, uses the established renderer/pose ownership rules, and restores presentation before handing back to gameplay. Original native body bones, colliders, controller ownership and ordinary inspection remain under the game's control. The 0.27.0 interface update preserves the 0.25.2 animation and hand-presentation implementation.

Reauthoring uses Unity 2022.3.43f1 and matching local native references. A recipient must be fitted and checked against its own rig and grip. A route in the catalog is not a live visual pass for every weapon, clothing set or attachment combination. The prebuilt bundles in a complete source package let the C# build proceed without rerunning animation authoring.

Card layout is independent of animation assets. The compact UI projects text, thumbnails, controls and list rows onto the saved category planes. Native mounting-point observations supply leader endpoints while bounded weapon movement moves the cards. No new weapon transforms, camera changes or animation timings are introduced by list expansion.
